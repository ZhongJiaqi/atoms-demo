目标与改动

让简单需求生成有辨识度、层次清楚、能实际操作的小型应用。生产代码仅调整 model.ts 的共享产品视觉要求及两条场景例子；不改模型、8k/16k预算、SDK参数、超时、JSON重试、沙盒、权限、环境或依赖。原极简偏好、已有项目风格和业务数据仍优先。

调研依据与适配

官方建议从字体、配色、动效和背景分别给出具体指导，并选定明确风格、避免通用模板。Anthropic 前端视觉提示词指南

本项目保留中文 XML 任务、上下文、约束、例子与 JSON 合同，按用户模板适配代码生成场景。只使用系统字体、CSS和内联SVG，不照搬外部字体、动画库或Claude专用API参数。该指南针对Claude，迁移到DeepSeek的效果仅由当前真实样本观察，不宣称普遍有效。

视觉要求

明确一种场景风格；主色加克制辅助色；桌面标题、正文和数字层级；按任务组织主次布局；空状态加入小型场景插画和下一步。保留可访问表单、页面内确认、减少动效设置、空数据与localStorage兼容。精致不等于添加无用业务、假数据或大量装饰。
