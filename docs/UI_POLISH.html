核心变化

  • 我的项目：一个成功项目一张卡片，隐藏 current_version=0 的草稿，不删除数据；移除首页“查看历史项目”和卡片版本列表。
  • 真实封面：由保存的不可变版本代码在独立受控沙盒构建，使用干净浏览器上下文截图。按项目与版本缓存 PNG，不在首页后台持续运行每个项目的 iframe。
  • 交互：按钮统一悬停/按下/键盘 focus 反馈；关键图标提供 hover 与 focus 文字提示。Enter 发送、Shift+Enter 换行，中文输入法组合期间不发送。
  • 手机：保留登录、历史版本、项目文件和控制台入口；底部对话/预览/代码切换。核心图标与认证控件的点击区域至少 44px；输入框 16px 避免手机自动放大。
  • 版本面板：轻量滑入；打开聚焦关闭按钮，键盘 Tab 保持在面板内，Esc/遮罩关闭，返回原触发控件。
  • 动画：短时淡入与位移、卡片微抬升、真实执行状态动效；尊重 prefers-reduced-motion，聊天滚动也取消平滑动画。
  • 诚实的入口：移除尚未实现的附件、折叠与虚假发布入口；分享/发布仍按用户要求暂缓，独立打开预览保留。

封面运行与安全边界

新接口使用当前用户会话与 RLS 验证项目所有权，不接受 user_id，不读取高权限密钥。截图同任务去重、一次运行一个、最多六个任务；普通请求仅允许本次随机 loopback origin 的 GET，所有 WebSocket 被关闭，WebRTC 构造器禁用、Service Worker 禁用，不带登录 Cookie 或应用用户存储。使用 Playwright 官方上下文 WebSocket 路由阻断通道。网络守卫经真实 Chromium 与本地服务器验证，但这不是操作系统级网络隔离证明。构建继续使用既有资源、文件权限与时间限制，截图结束关闭浏览器与 Vite 并回收临时目录。

PNG 位于 generated-projects/.thumbnails，是可重建缓存，不是永久代码存储。服务器缓存最多32MiB，按最旧PNG回收、原子rename写入；浏览器 private,no-store，切换账号必须重新鉴权。2026-10-14用户明确批准后，Playwright 1.64.0已声明为直接运行依赖并更新锁文件，不升级其他包。线上还需要专用截图/沙盒 adapter 及 Chromium 运行时，不能直接承诺 Vercel 可运行。截图浏览器目前未加入既有 Vite 的 RSS 监控，在线公开前需要独立资源隔离。
