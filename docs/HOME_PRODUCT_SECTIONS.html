交互与适配

场景行为
CSS 视口宽度 ≥ 1000px、高度 ≥ 700px，且为精确指针介绍段 min-height: 100dvh，CSS scroll-snap proximity 轻吸附；不拦截 wheel，不锁住屏幕。规则仅在首页存在时生效。
手机、窄屏、低高度或高倍缩放后的窄视口宽度不足 1000px 或高度不足 700px 时采用单列自然高度，关闭吸附；完整保留文字、示意与开始入口。
减弱动态效果关闭吸附和平滑滚动，保持内容直接可见。精确指针条件不满足时也不启用吸附与全屏最小高度。
“从一个想法开始”真实锚点返回现有需求框并聚焦，保留已输入内容；不提交、不调用模型。
